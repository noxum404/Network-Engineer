# Network Lab

A hands-on networking portfolio documenting network configurations, lab topologies, and troubleshooting scenarios.

## Topics
- VLAN and Trunking
- Routing and Switching
- Inter-VLAN Routing
- IP Addressing and Subnetting
- Network Troubleshooting

## Lab Environment
- Cisco Packet Tracer
- GNS3 / EVE-NG
- Cisco IOS CLI

## Goal
To build, test, and document reliable network infrastructures through practical labs.
